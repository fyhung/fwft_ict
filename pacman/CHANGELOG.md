# Changelog

## 0.3.0 — Summer 2026

- Added the supplied beginning, chomp, fruit, Ghost, death, extra-life, and intermission sound effects.
- Added two synchronized bonus fruits per round: a 100-point cherry after 70 dots and a 300-point strawberry after 170 dots.
- Added one extra shared Pac-Man life when the Pac-Man team first reaches 10,000 points.
- Added fruit collection to Pac-Man MVP statistics.

## 0.2.0 — Summer 2026

- Added visible project, school, course, creator, and ChatGPT attribution.
- Added a **None** cosmetic option.
- Added manual Pac-Man/Ghost assignment controls for the host.
- Added explicit in-app version display.

## 0.1.0

- Initial local-network multiplayer release with a Windows portable host.
