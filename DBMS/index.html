儲存、備份與 Firebase

瀏覽器會自動將 SQLite database bytes 及介面狀態儲存至 IndexedDB。下載的 JSON 可在另一部電腦匯入。登入 Google 後，Firebase Firestore 會把資料庫分成多個 chunk 儲存，毋須 Firebase Storage 或付費 billing plan；目前雲端資料庫上限為 10 MB。

雲端專案綁定帳戶並有 revision 檢查，避免較舊瀏覽器版本覆蓋較新版本。重要專案仍建議定期下載 JSON 備份。

驗證、警告與復原

SQLite 拒絕編輯或貼上時，系統會顯示錯誤訊息，復原原值，並以淡紅色短暫標示問題儲存格。套用外鍵、TEXT 輸入格式或數值／日期範圍前，系統會先檢查現有資料並列出所有不符合的值。

外鍵亦會阻止刪除仍被子資料表使用的父記錄，並保護被引用的父欄位不被重新命名、刪除或取消唯一性。
