Click the glowing Lego-style blocks to assemble a query. The palette only enables blocks that fit the current position. Once the query is valid, the source table transforms immediately.

    
Edit anywhere: Click a thin gap in the query to move the glowing insertion cursor, then choose a palette block. Click an existing SQL block to delete it. Undo restores the previous insertion or deletion.

    
Match every target column, row, value, and ordering exactly. Each inserted block costs 1 point, each Undo costs another point, and time costs 1 point every 2 seconds. There is no move limit, and you can keep solving at zero.

    
Tip: Punctuation and formatting are wired automatically, so you only pay for meaningful SQL blocks.
