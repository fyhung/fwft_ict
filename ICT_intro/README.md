# 資訊及通訊科技科｜SVG 瀏覽器簡報

這是一套填滿瀏覽器視窗、以 16:9 投影為主要比例的瀏覽器簡報。內容依照上一年度 PDF 的故事結構重新編排，使用「可愛角色 × 科技介面」視覺風格，並以 HTML、CSS、行內 SVG、點陣角色圖片和像素寵物混合呈現。

## 開啟方式

在專案根目錄啟動本機網站伺服器，然後瀏覽：

`http://127.0.0.1:4173/ICT_intro/`

## 操作

- 按畫面下方的左右按鈕換頁。
- 鍵盤可使用 `←`、`→`、`Page Up`、`Page Down` 或空白鍵。
- `Home` 回到第一張，`End` 前往最後一張。
- 狀態列的章節名稱可以直接跳到「課程內容」、「考核模式」、「合適同學」和「升學／就業」。
- 網址中的 `#slide-數字` 可直接連到指定投影片。
