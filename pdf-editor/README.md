# 紙上｜本機 PDF 編輯器

一個完全在瀏覽器本機運作的單頁 PDF 編輯工具。PDF 不會上傳至任何伺服器。

## 使用

直接雙擊 `index.html`。這是完整的單檔版本，不需要安裝或啟動伺服器。

`editor-source.html` 是 Vite 的開發原始檔；一般使用者只需開啟 `index.html`。

## 開發

```powershell
npm install
npm run dev
```

## 功能

- 開啟 PDF 並從縮圖選擇頁面
- 繪製可拖曳的矩形與直線
- 插入可拖曳的中英文文字方塊
- 控制字型、字級、顏色、字距與行距
- 下載目前頁面為單頁 PDF

匯出的單頁 PDF 會保留原頁面的向量內容，並將新增的文字、矩形和直線寫成真正的 PDF 文字與向量物件。預覽和匯出共用頁面座標、字型資料、換行及基線計算；縮放或改變視窗尺寸不會改變物件在 PDF 上的位置。亦支援旋轉頁面與裁切頁面。

內建 Noto Sans TC 黑體及 Noto Serif TC 明體。其他未載入的字型會明確標示替代字型，預覽和匯出均使用同一替代字型。如需真正的新細明體、標楷體、Arial 等，請在選取文字方塊後按「載入本機字型」（支援此功能的 Chrome／Edge 需授予字型權限），或選擇字型後按「匯入字型檔」載入 TTF、OTF 或 TTC 檔案。字型資料不會上傳，且只保留於目前的工作階段。

文字方塊可拖曳四角調整寬高，文字依寬度換行，超出高度的文字在預覽與匯出中均會裁切。字級最低 3 pt；10 以下以 0.5 pt 增減，10 以上以 1 pt 增減。
