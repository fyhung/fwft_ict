# 紙上｜本機 PDF 編輯器

一個完全在瀏覽器本機運作的單頁 PDF 編輯工具。PDF 不會上傳至任何伺服器。

## 使用

直接雙擊 `index.html`。這是完整的單檔版本，不需要安裝或啟動伺服器。

`editor-source.html` 是 Vite 的開發原始檔；一般使用者只需開啟 `index.html`。

## 開發

```powershell
npm install
npm run dev
```

## 功能

- 開啟 PDF 並從縮圖選擇頁面
- 繪製可拖曳的矩形與直線
- 插入可拖曳的中英文文字方塊
- 控制字型、字級、顏色、字距與行距
- 下載目前頁面為單頁 PDF

匯出的單頁 PDF 會保留原頁面的向量內容，並將新增的文字、矩形和直線寫成真正的 PDF 文字與向量物件。繁體中文會嵌入 Noto Sans CJK TC 字型，因此可保持清晰並可選取、搜尋。
