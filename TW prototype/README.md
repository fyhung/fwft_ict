# 路路通 • 地地淨 — Prototype v1.0

Windows：雙擊 **Start prototype.cmd**，自動啟動僅限本機的網頁伺服器並開啟預設瀏覽器（通常為 `http://127.0.0.1:4186/`）。用完雙擊 **Stop prototype.cmd**。使用 Windows 內建 PowerShell，無需安裝 Python、Node.js 或其他套件。按 F11 或頁面「全螢幕」展示。

請以 localhost 運行真實地圖。直接雙擊 `index.html` 會使用離線示意圖，因為 `file://` 沒有正常 HTTP Referer，可能被 OpenStreetMap 圖磚服務封鎖。localhost 不會把網站公開到互聯網；真實地圖圖磚仍需要網絡連線。若預設連接埠被佔用，啟動器會嘗試 4187–4196。伺服器在背景運行，使用 Stop prototype.cmd 停止。重複點選啟動器會開啟同一個運行中的服務。

## 三分鐘示範

1. 點選「日間平峰」，觀察沙田地圖與車隊，點選左側坑洞測試按鈕。
2. 右側點選「覆核屬實並分流」，再確認，查看「已分流」及地圖綠色標記。
3. 注入「AI 誤報測試」，查看紙箱情境，點選「AI 誤報」並確認，觀察攔截率。
4. 切換「夜間低照度」，觀察 0.65 → 0.85 的門檻與提示。
5. 使用「覆蓋與盲點」開關、旺角／沙田視角、前向／側向鏡頭。
6. 匯出 JSON 保存本次事件與覆核紀錄，或重設重新開始。

## 運行

- HTML 內含所有介面 CSS、互動 JavaScript 與模擬引擎；`assets` 存放本地函式庫及參考照片。
- Leaflet 1.9.4 和 Chart.js 4.4.8 已本地保存，不依賴 CDN 啟動。CSS 直接內嵌，無需 Tailwind 執行環境。
- 真實 OpenStreetMap 底圖需要互聯網。四次圖磚載入失敗會切換離線街區示意圖，也可手動切換。示意圖並非精確街道底圖。
- 每 60 秒自動產生一筆情境相關事件，夜間置信度不足會過濾。自動事件最多累積 50 筆；手動注入仍可用。暫停會停止車隊、RAM 動畫及自動事件，人工操作仍可用。
- 頁面資料只存在記憶體。關閉或重新載入會清除紀錄；先匯出 JSON 可保存。
- 沒有政府 API、外部硬件、攝像頭、定位權限、資料庫或後端服務。所有部門分流均為本地狀態變更。

## 示範與實測的界線

所有車輛路線、事件座標、偵測框、置信度、GPS/VIO、RAM 抹除及私隱遮罩都是模擬。照片只是本地參考素材，並非該座標的真實現場或實時串流。程式未執行 YOLO、人臉或車牌偵測、AI 訓練、真正記憶體安全抹除或法規合規驗證。規格中的 30 ms、FLOPs −45.2%、VIO 誤差及車隊總數均非本原型實測。

有效率 = 人工確認筆數 / 已覆核筆數；誤報攔截率 = 剔除筆數 / 已覆核筆數。沒有已覆核樣本時顯示「—」。60.57% 僅作學生報告的文獻參考，不冒充本系統準確率。所有預警均先進入「待覆核」，必須經兩步人工確認後才模擬分流。
