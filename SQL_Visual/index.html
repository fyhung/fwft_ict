Teaching Note

The prototype visualizes SQL's logical stages. GROUP BY visibly assigns rows into groups before aggregate values are produced; HAVING then filters whole groups. JOIN uses a nested-loop comparison and ORDER BY uses adjacent swaps for teaching clarity; real database engines may use different physical algorithms.
